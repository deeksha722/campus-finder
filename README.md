# Campus Finder

## About the Project

Campus Finder is a simple web application developed using Python and HTML. It demonstrates basic web development and database integration.

## Technologies Used

* Python
* HTML
* SQLite 

## Project Structure

* `app.py` – Python application logic.
* `index.html` – HTML webpage interface.
* `campus.db` – Database file used by the application.

## Features

* Simple web-based interface.
* Python-based application logic.
* Database integration for storing or retrieving information, depending on the implementation.

## How to Run

1. Install Python on your system.
2. Install any required Python packages used by `app.py`.
3. Open a terminal in the project folder.
4. Run the application using the appropriate Python command, such as `python app.py`.
5. Open the local address displayed in the terminal, if the application starts a web server.

## Purpose

This project demonstrates basic skills in web development, Python programming, and database integration.
